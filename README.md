# Group Invariant Statistics
Code base for "Group-Invariant Statistics Determine Embedding Geometry: Harmonic Analysis of Representations from Bach to the Night Sky"

## Setup

The repo contains a `pyproject.toml` and `uv.lock`.  To create and activate the environment, run:

```bash
uv sync
source .venv/bin/activate
```

Or run a script without activating, i.e.: `uv run python months/months.py`.

# Code Layout
The folders months, music, and celestial contain the code for their corresponding experiments in the paper.  For more details
on their respective scripts, view their individual README.md files.
