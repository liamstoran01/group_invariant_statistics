# group_invariant_statistics
Code base for "Group-Invariant Statistics Determine Embedding Geometry: Harmonic Analysis of Representations from Bach to the Night Sky"

## Setup

The repo ships `pyproject.toml` and `uv.lock`, not a `.venv`. From this
directory, create the environment and activate it:

```bash
uv sync
source .venv/bin/activate
```

Or run a script without activating: `uv run python months/months.py`.

See `months/README.md` and `music/README.md` for data and script steps.
